4 Modeling

4.1 Prediction Target

Analysis: The prediction task is to forecast census-tract-level eviction filings at monthly and quarterly time scales. We evaluate both count prediction and high-risk tract classification so the model can support short-term rental assistance targeting while still checking whether it identifies the highest-risk places.

Code 
library(broom)

score_model <- function(actual, predicted) {
  tibble(
    MAE = mean(abs(actual - predicted), na.rm = TRUE),
    RMSE = sqrt(mean((actual - predicted)^2, na.rm = TRUE)),
    Correlation = cor(actual, predicted, use = "complete.obs")
  )
}

classification_scores <- function(data, truth, pred) {
  tp <- sum(data[[truth]] == 1 & data[[pred]] == 1, na.rm = TRUE)
  fp <- sum(data[[truth]] == 0 & data[[pred]] == 1, na.rm = TRUE)
  fn <- sum(data[[truth]] == 1 & data[[pred]] == 0, na.rm = TRUE)
  tn <- sum(data[[truth]] == 0 & data[[pred]] == 0, na.rm = TRUE)

  tibble(
    Accuracy = (tp + tn) / (tp + tn + fp + fn),
    Precision = ifelse(tp + fp == 0, NA, tp / (tp + fp)),
    Recall = ifelse(tp + fn == 0, NA, tp / (tp + fn)),
    F1 = ifelse(
      (tp + fp) == 0 | (tp + fn) == 0,
      NA_real_,
      2 * ((tp / (tp + fp)) * (tp / (tp + fn))) / ((tp / (tp + fp)) + (tp / (tp + fn)))
    )
  )
}

evaluate_models <- function(data, split_name, model_specs, baseline_var) {
  bind_rows(lapply(names(model_specs), function(model_name) {
    spec <- model_specs[[model_name]]

    predicted <- if (!is.null(spec$type) && spec$type == "baseline") {
      pmax(data[[baseline_var]], 0)
    } else {
      predict(spec$model, newdata = data, type = "response")
    }

    predicted <- pmax(predicted, 0)

    score_model(data$filings_next, predicted) %>%
      mutate(model = model_name, split = split_name)
  }))
}

6 Policy Application

6.1 Rental Assistance Targeting

This model supports three complementary policy uses: proactive rental assistance targeting, legal aid allocation, and housing agency early warning.

Rental assistance targeting. Monthly tract-level forecasts enable city agencies and nonprofit partners to identify neighborhoods at elevated eviction risk before filings enter the court system. This proactive approach shifts resources upstream—toward emergency rental assistance, tenant counseling, and direct outreach—rather than waiting for households to reach formal proceedings.

Legal aid allocation. Legal aid organizations face persistent capacity constraints that prevent uniform coverage across all neighborhoods. Predicted high-risk tracts can guide the deployment of outreach events, mobile legal clinics, and tenant referrals to where demand is likely to peak, maximizing the impact of limited staff resources.

Early warning dashboard. Integrated into a monthly dashboard, the model can display predicted filing counts, renter-adjusted risk rates, and high-risk tract flags across Philadelphia. This gives housing agencies a consistent, forward-looking view of where eviction pressure is building and supports timely, coordinated intervention.

6.2 Equity and Safeguards

The model must be used exclusively to expand support for renters, not to surveil, penalize, or stigmatize high-risk neighborhoods. The data show that Black-majority tracts have higher average eviction filings. This reflects structural inequities in Philadelphia’s housing market, including unequal exposure to rent burden and housing instability. It describes neighborhood-level conditions, not characteristics of individual residents or communities.

Four safeguards should govern any policy deployment:

First, predictions should be restricted to supportive interventions like rental assistance, legal aid outreach, tenant counseling, and community-based prevention. The model must not be used for landlord screening, tenant eligibility determinations, code enforcement targeting, or any punitive purpose.

Second, the model should operate at the census tract level, not the household level. Tract-level targeting focuses resources on neighborhoods with elevated collective risk, avoiding the harms of labeling individual tenants.

Third, all high-risk tract designations should be reviewed by housing agencies and community partners before resources are deployed. Human oversight is especially important given that residual diagnostics show larger prediction errors in high-filing tracts—the neighborhoods most critical for intervention are also the hardest to forecast accurately.

Fourth, the city should monitor whether model-informed resources reach the neighborhoods of greatest need. Where the model systematically underpredicts risk or where assistance fails to arrive as planned, both the model and the implementation process should be revised.

7 Limitations

7.1 Data Limitations

The analysis relies on eviction filing records, which measure court activity rather than completed evictions or the full range of housing instability. Households experiencing informal displacement, “cash for keys” pressure, or severe rent burden without a filed case are not captured. Sealed records are excluded because they lack usable tract identifiers, which may cause undercounting in some areas. Finally, the ACS housing variables are tract-level estimates from a single survey year and do not align perfectly with month-to-month variation in filings.

7.2 Model Limitations

The model predicts eviction risk at the census tract level and is not designed for individual-level inference and it should never be used to make decisions about specific tenants or landlords. Although the preferred monthly model outperforms the quarterly specification, it produces larger errors in high-filing tracts, precisely the areas where accurate prediction matters most for intervention. The model captures persistent temporal patterns well, but it cannot fully account for sudden policy shifts, economic shocks, landlord behavior, or household-level circumstances.

7.3 Policy Limitations

Predictions alone do not resolve eviction risk. Effective implementation requires adequate rental assistance funding, sufficient legal aid capacity, trusted community partnerships, and timely data updates. There is also a misuse risk: if the model is deployed outside its intended supportive purpose, high-risk labels could be repurposed for exclusion or punitive action. The model should therefore be treated as a decision-support tool for prevention, not as an automated rule for benefit allocation or neighborhood evaluation.

8 Conclusion

8.1 Technical Takeaways

Recent eviction filing history is the strongest predictor of short-term future filings. Monthly forecasting consistently outperforms quarterly forecasting, as quarterly aggregation obscures short-term temporal signal. Adding structural covariates such as rent burden, household income, and neighborhood composition does not improve out-of-sample performance; in most specifications, it increases prediction error. The negative binomial models with structural covariates are better suited for interpreting why certain tracts carry higher baseline risk than for short-term forecasting.

8.2 Policy Takeaways

The model is best used as an early warning tool for rental assistance targeting, legal aid allocation, and housing agency monitoring. It can identify census tracts where eviction pressure is likely to rise, enabling agencies and nonprofit partners to intervene before filings spike. Predictions should be used only to expand supportive services for renters, and must be paired with human review and equity monitoring to ensure resources reach those most in need.
